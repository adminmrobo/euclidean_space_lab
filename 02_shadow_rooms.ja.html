6号室

影がいちばん近い答え

点から線へまっすぐ下ろした足もと

原資料カード 06/10 · @eeanimation方法：影（正射影）を求める日常：正午の棒の影

なぜこの方法を使うのか

  1. 問題 — モデルが出せる答えが1本の線（直線）の上にしかないとき、正解はたいていその線の外にあります。
  2. 前の部屋の限界 — 5号室で座標は読めましたが、線上のどの点が正解にいちばん近いかはわかりません。
  3. 解決法 — 正解から線へ直角に下ろした足もと（影）が、いちばん近い点です。
かんたんに言うと — 斜めに下ろすと斜辺になって必ず長くなります。まっすぐ下ろした足もとがいちばん短いのです。

数式が苦手な助手が代わりに尋ねます

助手 proj_u(v) = (v·u ÷ u·u) u… 分数の中に点が2つもあります！

学校数学で見ると — 正射影、垂線の足

式のかけら意味
v·uv と u の重なりスコア
u·uu の長さの二乗
v·u ÷ u·uu を何倍に伸ばせば影になるか
p影（いちばん近い点）
r = v − pずれた分 — いつも u と直角
数字で一度やってみる
v = (3, 2)、u = (1, 0) → 3 ÷ 1 = 3倍 → p = (3, 0)、r = (0, 2)、r·u = 0
u = (2, 1) → v·u = 8, u·u = 5 → p = 1.6 × (2, 1) = (3.2, 1.6), r = (−0.2, 0.4), r·u = 0
身長 160・162・164 を数字1つで：162なら誤差の二乗和 4 + 0 + 4 = 8、161なら 1 + 1 + 9 = 11 → 平均162が影
助手 ずれた分がいつも直角、というのが要なんですね。だからいちばん短いと。

日常でいえば

正午に棒を立てると、影はちょうど足もとにできます。日が斜めになるほど影は長くなります。

機械学習では

予測線引き（最小二乗回帰）は、正解を "モデルが出せる答えたち" へ影として落とす作業です。いくつかの値の平均も影です。

博士線の上で v にいちばん近い点はどこでしょう？
アバボットv の先からいちばん近い目盛り、3 にだいたい合わせればいいでしょ！
ショウジョウバエ研究員線の向き u を回してみて。そのときも3かな？
実験パネル 6原資料カード06の描き直し · 線の向き u を回してみてください

解説

u を回しても r·u はいつも0です。ずれた分は線と直角です。

原資料の結論どおり、影は u を通る線の上でいちばん近い点です。

アバボットの "だいたい3" は、u が横向きのときだけ当たります。

📝 原資料と違う書き方をした箇所 — 原資料は u を太字と斜体で混ぜて書いています。このページでは1種類の書体にそろえます。

この部屋の限界 — 影を落とす "床" が線1本だけでした。平面やもっと大きな床、それに陣営を分ける板はどう使うのでしょう？→ 7号室
教材の Python コードで見ると（わからなくても大丈夫です）
p = (v @ u) / (u @ u) * u

重なりスコアの比の分だけ u を伸ばして影を作ります。

確認クイズ — 身長を3回測ったら 170・172・177 でした。誤差の二乗和がいちばん小さい代表値（影）は？
平均173が影です。誤差の2乗和は9 + 1 + 16 = 26で、いちばん小さくなります。172なら4 + 0 + 25 = 29、173なら9 + 1 + 16 = 26です。平均が影です。
7号室

線・平面・仕切り

nマスの部屋の仕切りは1マス少ない板

原資料カード 07/10 · @eeanimation方法：仕切りの式で陣営を分ける日常：運動場の真ん中の線

なぜこの方法を使うのか

  1. 問題 — スパムメールと通常メールを分けるには、部屋の中に仕切りを立てる必要があります。
  2. 前の部屋の限界 — 6号室の床は線1本でした。もっと広い床と、陣営を分ける板が必要です。
  3. 解決法 — 仕切りに刺さった矢印（法線）n との重なりスコアで、"どちら側か" を判定します。
かんたんに言うと — 運動場の真ん中の線1本で、紅組・白組を分けるのと同じです。

数式が苦手な助手が代わりに尋ねます

助手 n·(x − p) = 0、ℝⁿ の超平面は n − 1 次元… n が2つの意味で出てきます！

学校数学で見ると — 直線・平面の方程式、点と平面の距離

式のかけら意味
x = p + tv出発点 p から v の方向に t だけ進む = 直線
n仕切りに刺さった矢印（法線）
n·(x − p) = 0仕切りの上のすべての点は n と直角
x₁ + 2x₂ + 2x₃ = 6n = (1, 2, 2) の仕切り
n − 1マスの数 n の部屋の仕切りは1マス少ない
数字で一度やってみる
軸と交わる点：(6, 0, 0)、(0, 3, 0)、(0, 0, 3) — 原資料と同じ
点 (2, 2, 2)：2 + 4 + 4 = 10 > 6 → 原点の反対側、仕切りまで (10 − 6) ÷ 3 ≈ 1.33
原点：0 < 6 → 原点側、仕切りまで 6 ÷ 3 = 2（n の長さ √(1 + 4 + 4) = 3）
助手 スコアを6と比べれば終わりですね。スパム判定器は思ったより単純です。

日常でいえば

運動場の線の左は紅組、右は白組です。線から遠いほど、はっきりその組です。

機械学習では

ロジスティック回帰・SVM のような分類器は、仕切り（決定境界）を立てます。仕切りから遠い点ほど、確信の強い判定です。

シア仕切り1枚で陣営が分かれるなんて、真ん中の線ですね！
モア仕切りにぴったりくっついた点は、どちらの陣営ですか？
ショウジョウバエ研究員点 P の3つの座標を変えて、スコアが6になる位置を探してみて。
実験パネル 7原資料カード07の仕切りの描き直し · 点 P の座標を変えてみてください

解説

スコアが6より大きければ原点の反対側、小さければ原点側、同じなら仕切りの上（境界）です。

仕切りの上の点は判断を保留します。実際の分類器も、境界近くの点にいちばん迷います。

3マスの部屋の仕切りは平面（2マス）です。nマスの部屋なら n − 1 マスの板です。

📝 原資料と違う書き方をした箇所 — 原資料は軸の名前 x と点の名前 x が重なっています（x = p + tv と x軸）。このページでは軸を x₁・x₂・x₃ に変え、仕切りの式も x₁ + 2x₂ + 2x₃ = 6 と書きます。原資料の "Hyperplane in ℝ³" は、3マスの部屋では平面と同じものです。

この部屋の限界 — 点をずらしたり回したりすると、仕切りや距離は変わるでしょうか？データを動かしてよいかどうかから確かめる必要があります。→ 8号室
確認クイズ — 仕切り x₁ + 2x₂ + 2x₃ = 6 で、点 (0, 0, 3) は？
0 + 0 + 6 = 6 → 仕切りの上（境界）です。元データの軸と交わる点 (0, 0, 3) です。スコアを計算してみてください：0 + 2×0 + 2×3 = 6。6と等しければ仕切りの上です。
8号室

ずらしても・回しても・裏返しても距離はそのまま

形を変えない動きと変える動き

原資料カード 08/10 · @eeanimation方法：距離を守る動きを選ぶ日常：写真を回す

なぜこの方法を使うのか

  1. 問題 — 写真を回したり座標の原点を動かしたりしても、データどうしの関係は同じでなければなりません。
  2. 前の部屋の限界 — 7号室までは、点をその場に置いたまま測っただけでした。動かすとどうなるかはわかりません。
  3. 解決法 — ずらす・回す・裏返すは距離と角度を守ります。伸ばすだけが距離を変えます。
かんたんに言うと — 紙の上の三角形をずらしても回しても裏返しても、同じ三角形です。拡大コピーだけが大きさを変えます。

数式が苦手な助手が代わりに尋ねます

助手 x′ = Qx + t、QᵀQ = I… 上付きの T と I は今度は何ですか？

学校数学で見ると — 平行移動、回転、対称移動、相似

式のかけら意味
tずらす — すべての点に同じ矢印を足す
Q回す・裏返すの表
QᵀQ = I回す・裏返すの表の条件：長さと角度を変えない
s倍に伸ばすすべての距離が |s|倍
|s| = 1このときだけ、伸ばしても距離を守る
数字で一度やってみる
(0, 0) から (3, 4) まで長さ5 → 90° 回すと (0, 0) から (−4, 3) まで長さ5
ずらす：2点に (−2, 1) を同じように足すと、差 B − A はそのまま → 距離もそのまま
2倍に伸ばす：長さ 5 → 10
助手 回転の表は、距離を守る表だけを選んで使うんですね。

日常でいえば

スマホの写真を回しても、顔は同じ顔です。拡大すると大きさだけが変わります。

機械学習では

写真を回したり裏返したりして学習データを増やします（データ拡張）。形がそのままなので、正解ラベルもそのままです。

博士動かしてもよい動きと、気をつけるべき動きがあります。
アバボット伸ばしても形は同じなんだから、距離もそのままでしょ！
ショウジョウバエ研究員伸ばすボタンを押して、3辺の長さを見てみて。
実験パネル 8原資料カード08の描き直し · ボタンとスライダーで三角形を動かしてみてください

解説

ずらす・回す・裏返すをどれだけ組み合わせても、3辺は 3 · 4 · 5 のままです。

伸ばすをオンにすると 6 · 8 · 10 になります。形（角度）は同じでも距離は変わります。

原資料のとおり、伸ばすのは |s| = 1 のときだけ距離を守ります。

この部屋の限界 — 動かしても距離が変わらないことはわかりました。次は "どの距離の内側までを近所とみなすか" の範囲を決める必要があります。→ 9号室
確認クイズ — 次のうち、2点間の距離を変える動きは？
3倍に伸ばすと、すべての距離が3倍になります。ずらすことと回すことは距離を保ちます。伸ばすことだけが距離を変えます。
9号室

半径rの内側 = 近所

円・球面・球、そしてマスが増えると起きること

原資料カード 09/10 · @eeanimation方法：半径で近所の範囲を決める日常：家から半径1km

なぜこの方法を使うのか

  1. 問題 — "近い顧客を何人か" ではなく、"距離 r 以内の顧客全員" を探したいときがあります。
  2. 前の部屋の限界 — 8号室までは、2点間の距離を測っただけでした。範囲を描いてはいません。
  3. 解決法 — 中心から距離 r 以下の点を集めると、2マスの部屋では円、3マスの部屋では球になります。
かんたんに言うと — 家を中心に半径1kmの円を描けば、その中の店が "近所の店" です。

数式が苦手な助手が代わりに尋ねます

助手 ‖x − c‖ = r と ‖x − c‖ ≤ r… 等号1つの違いで名前が変わるんですか？

学校数学で見ると — 円の方程式、球の方程式、指数

式のかけら意味
c中心
‖x − c‖ = r中心からちょうど r 離れた点たち = 外殻（円・球面）
‖x − c‖ ≤ rr の内側全体 = 中身の詰まった球
x² + y² = r²中心が原点のときの円
0.9ⁿnマスの球で、半径0.9の内側が占める体積の割合
数字で一度やってみる
半径1：円の面積 π × 1² ≈ 3.14、球の体積 4π ÷ 3 ≈ 4.19
半径0.9の内側の割合：2マス 0.81（81%）、3マス 0.729（73%）
10マス 0.9¹⁰ ≈ 0.349（35%）、100マス 0.9¹⁰⁰ ≈ 0.0000266 — ほぼすべてが外殻
助手 マスが多いと、球の中身が空っぽのようになるんですね。不思議です。

配達アプリの "半径2km以内の店" がこの円です。

機械学習では

半径による近傍探索、おかしな値探し（半径内に近所がなければ怪しい）に使います。マスがとても多いと、すべての点が同じくらい遠くなります（次元の呪い）。

シア半径を大きくすると近所が増えますよね？図でぱっとわかります。
モア原資料のタイトルに n-Balls とあるのに、nマスの球の話はありません。
博士だからこのページで実験を1つ足しました。2つ目のパネルを見てください。

解説

半径を大きくすると近所の数が増えます。店が均等に散らばっていれば、円の面積 πr² に比例して増えます。

マスの数を増やすと、体積の大部分が外殻へ移ります。100マスの球では、半径0.9の内側はわずか 0.003% です。

原資料カードは中心 c で見出しボックスを書き、下の式は中心が原点のときのものです。このページでは "中心を原点に置いた場合" と明記します。

10号室

この部屋が使われる場所と、まっすぐな定規の限界

単位をそろえる必要があり、曲がった表面ではまっすぐな定規は短く測る

原資料カード 10/10 · @eeanimation方法：単位合わせ、弧と弦の比較日常：飛行機の航路

なぜこの方法を使うのか

  1. 問題 — 工学（位置）、グラフィックス（回転）、データ分析（最近傍）は、すべてこの部屋の距離を使います。
  2. 前の部屋の限界 — でも9号室までは、すべてのマスの単位が同じだと仮定していました。
  3. 解決法 — 単位をそろえ（特徴量スケーリング）、曲がった表面では表面に沿って測ります。
かんたんに言うと — 身長を mm で書くと、身長の数字が10倍になって距離を独り占めします。

数式が苦手な助手が代わりに尋ねます

助手 d_surf = Rθ、d_Euc = 2R sin(θ/2)… なぜ急にサインが出てくるんですか？

学校数学で見ると — 単位の変換、弧の長さ、三角関数

式のかけら意味
‖x − y‖₂3号室のまっすぐな定規の距離
y* = argmin距離がいちばん小さい y を選ぶ（最近傍）

2R sin(θ/2)地中をまっすぐ掘った長さ（弦）
数字で一度やってみる

モア身長は cm、体重は kg なのに、そのまま一緒に足していいんですか？
アバボット数字は数字でしょ！単位なんて関係ないって！

解説

アバボットの言葉とは違い、単位は距離を変えます。原資料も "特徴量スケーリングが重要だ" と書いています。

180° なら弧は 20,015km、弦は直径の 12,742km です。

廊下の突き当たりの果てしない部屋

次の編はヒルベルト空間です。ここでは教えず、それが何で、なぜ必要かだけを紹介します。

① 今日の部屋のまとめ

定規（距離）でどれだけ遠いか、分度器（重なりスコア）でどれだけ似ているか、影でいちばん近い答えがどこかを測りました。

② この部屋にできないこと

マスの数が決まっていなければなりません。音・センサーの曲線・株価の流れのように果てしなく続くデータは入れられません。

1 秒の音楽でも、CD 音質で書き取ると数字は 44100 個になります。それでも音の曲線そのものは途切れなく続きます。

③ ヒルベルト空間とは

  • 定規と分度器はそのままに、部屋を果てしなく広げたものです。
  • 曲線1本を点1つと見て、曲線どうしでも「どれだけ遠いか・どれだけ似ているか・影」を測ります。
  • 今日学んだルールがほとんどそのまま通用します。変わるのはマスの数だけです。
