# 수포자 스킬 검토 — 자와 각도기의 방 (2026-11-21)

독자 가정: 혼합형(수포자형 + 통포자형). 검토 모드, 사용자 승인 후 기존 페이지를 직접 고침.

## 진단과 반영
| 원칙 | 전 | 후 | 반영 |
|---|---|---|---|
| P1 원리 먼저 | 2 | 3 | 조수 수식 상자 첫 줄에 "이 식은 ○○을 재는 식이래요" (10개 방) |
| P2 과정 한 번 | 3 | 3 | 코드 상자에 결과값과 "손계산과 같음" 한 줄 (5곳) |
| P3 기호는 말로 먼저 | 2 | 3 | 같은 말 풀이가 기호 앞에 옴, 0편 「기호 읽는 법」 표 |
| P4 맥락 | 3 | 3 | — |
| P5 현장 | 3 | 3 | — |
| P6 AI 결과 판단력 | 1 | 2 | AI 판단 코너 3곳: 3번 방(거리 7?), 4번 방(cos 1.3?), 10번 방(단위 확인) |
| P7 존중하는 어조 | 3 | 3 | — |

- 통포자형 처방: 3·4·6·10번 방 풀이 끝에 「한 문장으로 말하면」 해석 문장.
- 용어 정확성: 3번 방 "제곱 오차(MSE)도 같은 식" → "빗나간 거리를 제곱해 축 수로 나누면 제곱 오차 평균(MSE)".
- P6이 3점이 아닌 까닭: ②편 6~9번 방에는 AI 판단 활동이 없음. 다음 보완 후보 — 6번 방 "AI가 그은 예측선의 빗나간 만큼이 선과 직각이 아니다?", 9번 방 "AI가 100축 데이터에서 가장 가까운 이웃이라며 고른 점".

## 함께 바꾼 표현 규칙
- 연구실 스킬과 결과물에서 '사다리'·'관통'·'칸' 표현을 쓰지 않는다.
- 이 콘텐츠에서는 칸 → 축(n축 방, 축 수), 칸막이 → 가름판, 사다리 → 흐름·순서로 바꿈.
