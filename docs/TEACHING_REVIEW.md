- 해석 막힘형 처방: 3·4·6·10번 방 풀이 끝에 「한 문장으로 말하면」 해석 문장.

- P6이 3점이 아닌 까닭: ②편 6~9번 방에는 AI 판단 활동이 없음. 다음 보완 후보 — 6번 방 "AI가 그은 예측선의 빗나간 만큼이 선과 직각이 아니다?", 9번 방 "AI가 100축 데이터에서 가장 가까운 이웃이라며 고른 점".

- 이 콘텐츠에서는 칸 → 축(n축 방, 축 수), 칸막이 → 가름판, 사다리 → 흐름·순서로 바꿈.

# 연구실 확장 스킬(ai-lab-extend) 적용 — v1.5 (2026-11-22)
요청: "수식 부분이 많아 더 쉽게". 독자 가정: 혼합형(수식 막힘형 처방 먼저).

## 바꾼 것
| 항목 | 전 | 후 |
|---|---|---|
| 조수 질문 | 수식을 그대로 읽으며 묻기(예: "u·v = Σuᵢvᵢ = ‖u‖‖v‖cos θ… 시그마랑 이중 막대가…") | 말로만 묻기(예: "두 화살표가 같은 쪽을 본다는 걸 숫자로 어떻게 말해요?") |
| 수식 상자 순서 | 질문 → 학교 수학 → 식 조각 표 → 숫자 | 질문 → **말로 하면** → **숫자로 한 번 해 보기** → 학교 수학 → (펼치기) 식과 식 조각 표 |
| 겉에 보이는 수식 | 방마다 2~5줄 | 0줄 — 식은 「식으로 보면 (펼치기 — 몰라도 됩니다)」 안에만 |
| 박사(친절한 교육자) | 수식이 많은 방에 안심 대사 없음 | 4번 방 "식은 펼치지 않아도 괜찮다…", 7번 방 현장 질문으로 열기 |
| 금지 별칭 | 문서 2곳·파일 이름 1곳 | 0건 (검토 기록 파일 이름을 TEACHING_REVIEW.md로 바꿈) |
