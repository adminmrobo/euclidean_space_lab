The Room of Rulers and Protractors

We start by plotting one row of numbers as a point, then measure distances and angles, and end by switching ruler sets.

By Ahn Sangsun (CEO, M-Robo Inc.) · About the author · 2026-11-19 · v1.4

New here? This page in 3 lines

  • What: Plot bundles of numbers as points, describe moves with arrows, and measure distances and angles.
  • Why it matters: Finding similar customers (distance) and finding people with similar tastes (angle) start here.
  • At work: If you see one row of customer or product data as a point, you can pick "the most similar one" with numbers.

No code or formulas required. This page deals only with real numbers (ordinary numbers).

Room 1

1-axis, 2-axis, 3-axis rooms, and the n-axis room

One bundle of numbers = one point in the room

Source card 01/10 · @eeanimationMethod: read numbers as coordinatesEveryday: a height and weight log

Why use this method

  1. Problem — One row of a customer log is several numbers. We want to measure how similar these rows are.
  2. Limit of the previous room — Looking at numbers only as a table, it's hard to say "close or far" at a glance.
  3. Solution — Treat each number as one axis, and plot each row as one point in the room.
In plain words — Height alone gives a number line, height and weight give a coordinate plane, and one more gives 3D coordinates.

The assistant, who finds math formulas hard, asks for you

Assistant They say this formula measures how far apart two points are. Euclidean space, ℝⁿ… even the names are scary. What is it?

In school math terms — the number line, the coordinate plane, 3D coordinates — and the distance between two points

Formula pieceMeaning
ℝAll real numbers (ordinary numbers with decimals)
ℝⁿEvery list of n real numbers in a row = an n-axis room
(x₁, …, xₙ)One point, with one number written for each axis
d(a, b) = |b − a|Distance in a 1-axis room = the difference of the two numbers
Try it with numbers
1 axis (height): Sia 160, Moa 163 → |163 − 160| = 3
2 axes (height, weight): (160, 50) and (163, 54) → √(3² + 4²) = √25 = 5
3 axes (+waist): add waists 64 and 76 → √(3² + 4² + 12²) = √169 = 13

In everyday terms

It's like sticking one pin on a map for each row of a membership list (height, weight, waist).

In machine learning

One row of data is one point. With 30 columns, it's a point in a 30-axis room (feature space). Words and photos are also turned into rows of numbers and placed as points (embedding).

Room 2

Points are places, arrows are moves

B − A = the arrow from home to the office

Source card 02/10 · @eeanimationMethod: find the move by subtractingEveryday: giving directions

Why use this method

  1. Problem — With two points, you want to say "from where to where, and how far."
  2. Limit of the previous room — Room 1's points only tell positions. They can't hold movement.
  3. Solution — Subtract the start point from the end point to get the move arrow (vector).
In plain words — A point is an address; an arrow is directions like "3 east, 2 north."

The assistant, who finds math formulas hard, asks for you

Assistant They say this formula writes down the path from one point to another. Points and vectors are both written like (3, 2), so what's the difference?

In school math terms — adding and subtracting vectors, position vectors

Formula pieceMeaning
A, BPosition (point)
v⃗ = B − AThe move from A to B (arrow)
B = A + v⃗Start point plus the move gives the end point
OA⃗The arrow from origin O to A (position vector)
Try it with numbers
A = (1, 1), B = (4, 3) → v⃗ = (4 − 1, 3 − 1) = (3, 2)
Check backwards: A + v⃗ = (1 + 3, 1 + 2) = (4, 3) = B
Assistant The numbers look the same, but a point means "here" and an arrow means "this much that way."

In everyday terms

A home address (point) and "3 blocks east, 2 blocks north" (arrow) are different information.

In machine learning

We see the difference between two pieces of data as an arrow. Calculations on word points like "king − man + woman ≈ queen" are this room's subtraction and addition.

Room 3

Pythagoras for any number of axes

Distance between two points = add the squared differences and take the root

Source card 03/10 · @eeanimationMethod: measure distance with PythagorasEveryday: straight-line distance on a map

Why use this method

  1. Problem — To find "the customer most similar to this one," near and far must be set by a single number.
  2. Limit of the previous room — Room 2's arrows have two or more numbers, so you can't compare sizes directly.
  3. Solution — Treat the arrow as a hypotenuse and get one length with the Pythagorean theorem.
Put simply — if you walk 3 across and 4 up, the straight-line distance back to the start is 5.

The assistant, who finds math formulas hard, asks for you

Assistant They say this formula measures the straight-line distance between two points in a room with any number of axes. d(A, B) = √((b₁ − a₁)² + … + (bₙ − aₙ)²)… What are the dots?

In school math terms — the distance between two points, the Pythagorean theorem

Formula pieceMeaning
bᵢ − aᵢDifference on the i-th axis
( )²Square the difference — negatives become positive
+ ⋯ +keep adding, once for each axis
√Undo the square to get back to the original unit
Try it with numbers
A = (1, 1), B = (4, 5) → across 3, up 4 → √(9 + 16) = √25 = 5
3-axis example: (1, 1, 1) and (3, 3, 2) → √(2² + 2² + 1²) = √9 = 3
Taking the alleyways, 3 + 4 = 7. The straight line is always the shortest
Assistant So the dots meant "repeat once for each axis." Now it doesn't scare me.

In everyday terms

A map app's "5km straight-line distance" is this calculation. The real road distance is longer.

In machine learning

Nearest-neighbor search (KNN) and grouping similar things (K-means) use this distance. Square how far the predictions missed and divide by the number of axes, and you get the mean squared error (MSE).

As Python code from the course notes (optional)

Computes the length of arrow B − A = the distance between two points in one line.

Result: 5.0 — same as the 5 we calculated by hand.

Room 4

Overlap score and angle

How much do two arrows point the same way?

Source card 04/10 · @eeanimationMethod: overlap score (dot product) and cos θEveryday: comparing two people's taste charts

Why use this method

  1. Problem — Recommendation apps look for "people with similar taste." Direction matters more than amount.
  2. Limit of the previous room — Room 3's distance treats someone who watched a lot and someone who watched a little as far apart, even with the same taste.
  3. Solution — Measure the angle between two arrows with the overlap score: multiply matching positions and add.
In plain words — If two arrows point the same way the score is big; at a right angle it's 0; pointing opposite ways it's negative.

The assistant, who finds math formulas hard, asks for you

Assistant They say this formula measures how much two arrows point the same way. u·v = Σuᵢvᵢ = ‖u‖‖v‖cos θ… Sigma and double bars all at once!

In school math terms — the dot product of vectors, cosine

Formula pieceMeaning
u·vOverlap score (dot product) — multiply matching positions and add them up
Σuᵢvᵢu₁v₁ + u₂v₂ + … (multiply each position and add them all)
‖u‖Length of arrow u (Room 3's distance)
θ (theta)Angle between two arrows
cos θThe angle turned into a score from −1 to 1. Same way 1, right angle 0, opposite −1
Try it with numbers
u = (3, 0), v = (2, 2) → u·v = 3×2 + 0×2 = 6
Lengths: ‖u‖ = 3, ‖v‖ = √8 ≈ 2.83 → cos θ = 6 ÷ (3 × 2.83) ≈ 0.707 → θ = 45°
Taste chart (action and romance titles watched): Sia (5, 1), Moa (4, 2) → 22 ÷ (5.10 × 4.47) ≈ 0.965
Assistant So cos θ close to 1 means "almost the same taste."

In everyday terms

Someone who watched 5 action and 1 romance and someone who watched 4 and 2 are very alike. That's a score of 0.965.

In machine learning

Cosine similarity finds similar products, documents, and customers. Attention scores in language models also start from the overlap score.

Explanation

Move v to (0, 2) and the score is 0, and the right-angle mark appears.

A score of 0 doesn't mean "useless"; it means "they don't affect each other." Like east-west and north-south.

A score of 0 means a right angle only when both arrows have nonzero length (source: nonzero vectors).

In one sentence — Sia's and Moa's taste profiles score 0.965 — very close to 1, so their tastes point in almost the same direction.

Check it

cos θ is always between −1 and 1. 1.3 is impossible, so have it redo the calculation. Most likely it skipped the step of dividing by the lengths.

This room's limit — Even if you know the angle, the coordinates depend on "which ruler you measured with" to write the numbers. → Room 5
As Python code from the course notes (optional)
u @ v / (np.linalg.norm(u) * np.linalg.norm(v))

Divide the overlap score by the product of the two lengths to get cos θ (cosine similarity).

Result: 0.7071… — same as the 6 ÷ (3 × 2.83) ≈ 0.707 we got by hand.

Check quiz — What is the overlap score of u = (1, 2) and v = (−2, 1)? How are the two arrows related?
1×(−2) + 2×1 = 0, so they are at a right angle.Multiply slot by slot and add: 1×(−2) + 2×1.
Room 5

A ruler set of unit-length rulers at right angles

Coordinates change depending on which ruler you measure with

Source card 05/10 · @eeanimationMethod: read coordinates with a ruler setEveryday: changing the reference for directions

Why use this method

  1. Problem — The same data gives different numbers depending on which reference (axes) you view it with.
  2. Limit of the previous room — Up to Room 4, we took the "horizontal and vertical" rulers for granted. What happens with other rulers?
  3. Solution — With a ruler set of unit-length rulers at right angles (an orthonormal basis), reading coordinates takes just one overlap score.
In plain words — Whether you give directions as east-west and north-south or as "along the river and across the river," the destination is the same.

The assistant, who finds math formulas hard, asks for you

Assistant They say this formula is the rule for reading coordinates with a ruler set. eᵢ·eⱼ = 1 or 0… What rule do these curly braces mean?

In school math terms — coordinates, vector components, unit vectors

Formula pieceMeaning
e₁, e₂The two rulers in the ruler set
v = 3e₁ + 2e₂3 in the e₁ direction, 2 in the e₂ direction
eᵢ·eᵢ = 1Each ruler has length 1
eᵢ·eⱼ = 0 (i ≠ j)Different rulers are at right angles
Coordinate = v·eᵢThe overlap score with that ruler is the coordinate
Try it with numbers
Standard rulers: v = (3, 2) → v·e₁ = 3, v·e₂ = 2
Rulers rotated 45°: e₁ = (0.71, 0.71), e₂ = (−0.71, 0.71) → coordinates (3.54, −0.71)
Length check: 3.54² + 0.71² ≈ 12.5 + 0.5 = 13 = 3² + 2²
Assistant The numbers change, but the sum of squares stays 13. Because the arrow itself hasn't changed!

In everyday terms

The same place can be described as "3 east, 2 north" or as "3.5 along the river, −0.7 across the river."

In machine learning

One-hot encoding gives each category its own unit-length ruler at right angles. Principal component analysis (PCA) rotates the ruler set toward where the data spreads out the most.
