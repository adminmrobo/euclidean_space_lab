1 号房间

1轴、2轴、3轴房间，以及 n 轴房间

一组数字 = 房间里的一个点

原始资料卡片 01/10 · @eeanimation方法：把数字读作坐标日常：身高·体重记录表

为什么用这个方法

  1. 问题 — 客户记录表的一行是多个数字。想测量这些行之间有多相似。
  2. 前一个房间的局限 — 只把数字看成表格，很难一眼说出"近·远"。
  3. 解法——把一个数看作一个轴，把一行数据画成房间里的一个点。
简单来说 — 只记身高是数轴，身高·体重是坐标平面，再加一个就是空间坐标。

2 号房间

点是位置，箭头是移动

B − A = 从家到公司的箭头

原始资料卡片 02/10 · @eeanimation方法：用减法求移动日常：指路

为什么用这个方法

  1. 问题 — 有两个点，就会想说"从哪里到哪里、走多少"。
  2. 前一个房间的局限 — 1 号房间的点只告诉位置。装不下移动。
  3. 解法 — 终点减去起点，就得到移动箭头（向量）。
简单来说 — 点是地址，箭头是"向东 3、向北 2"这样的指路。

由害怕数学公式的助手代为提问

助手 点和箭头看起来都像 (3, 2)，到底有什么不同呢？
用话来说 — 用到达的位置减去出发的位置，就得到连接两者的箭头。
用数字算一遍
A = (1, 1), B = (4, 3) → v⃗ = (4 − 1, 3 − 1) = (3, 2)
反向验证：A + v⃗ = (1 + 3, 1 + 2) = (4, 3) = B

用学校数学来看 — 向量的加减法、位置向量

用公式来看（展开 — 不懂也没关系）
v⃗ = B − A, B = A + v⃗
公式片段含义
A, B位置（点）
v⃗ = B − A从 A 到 B 的移动（箭头）
B = A + v⃗起点加上移动就是终点
OA⃗从原点 O 到 A 的箭头（位置向量）
助手 数字形状一样，但点是"这里"，箭头是"往那边这么多"啊。

用日常来比喻

家的地址（点）和"向东 3 个街区、向北 2 个街区"（箭头）是不同的信息。

在机器学习中

用箭头看两个数据之差。在词语点上，"国王 − 男人 + 女人 ≈ 女王"这样的计算就是本房间的减法·加法。

博士A 是家，B 是公司。用数字说说上班路线吧？
西娅从图上看，绿色箭头就是上班路线吧？
果蝇研究员把 B 拖动一下。看看箭头的数字怎么变。
实验面板 2重绘原始资料卡片 02 · 拖动蓝点 B 试试

解说

不论把 B 移到哪里，v⃗ = B − A 都会随之改变。

同样的箭头从哪里出发都是同样的移动。所以可以比较差值。

这个房间的局限 — 箭头告诉方向和量，但不能用一个数字说出"有多远"。 → 3 号房间
确认测验 — A = (2, 5)，B = (6, 2) 时，从 A 到 B 的箭头是？
B − A = (6 − 2, 2 − 5) = (4, −3)。用终点（B）减去起点（A）：(6 − 2, 2 − 5)。
3 号房间

无论几个轴都是勾股定理

两点间距离 = 差的平方相加再开根号

原始资料卡片 03/10 · @eeanimation方法：用勾股定理量距离日常：地图上的直线距离

为什么用这个方法

  1. 问题 — 要找"与这位客户最相似的客户"，就得用一个数字确定远近。
  2. 前一个房间的局限 — 2 号房间的箭头有两个以上的数字，无法直接比较大小。
  3. 解法 — 把箭头看作斜边，用勾股定理算出一个长度。
简单来说——横走 3、竖走 4，到出发点的直线距离就是 5。

由害怕数学公式的助手代为提问

助手 轴变多了，距离要怎么量呢？图都画不出来了。
用话来说 — 在每根轴上求出差值并平方，全部加起来后再开根号。不管有几根轴，步骤都一样。
用数字算一遍
A = (1, 1)，B = (4, 5) → 横 3，纵 4 → √(9 + 16) = √25 = 5
3轴例子：(1, 1, 1) 和 (3, 3, 2) → √(2² + 2² + 1²) = √9 = 3
走小巷的话是 3 + 4 = 7。直线永远最短

用学校数学来看 — 两点间距离、勾股定理

用公式来看（展开 — 不懂也没关系）
d(A, B) = √((b₁ − a₁)² + (b₂ − a₂)² + ⋯ + (bₙ − aₙ)²)
公式片段含义
bᵢ − aᵢ第 i 个轴上的差
( )²差取平方 — 负数也变成正数
+ ⋯ +按轴的个数一直加下去
√解开平方，回到原来的单位
助手 原来省略号的意思是"按轴的个数重复"。现在不怕了。

用日常来比喻

地图应用的"直线距离 5km"就是这个计算。实际道路距离比它长。

在机器学习中

最近邻查找（KNN）、把相似的归为一组（K-means）都用这个距离。把预测偏离的距离平方后除以个数，就是均方误差（MSE）。

茉雅就算有 100 个轴，这个式子也照样管用吗？
算盘宝横 3、纵 4，所以距离是 7 吧！我全押这个数！
果蝇研究员可疑。把 A 和 B 拖一拖，亲自量量看。
实验面板 3重绘原始资料卡片 03 · 拖动 A 和 B 试试

解说

算盘宝的 7 是绕小巷走的距离。用直尺量是 5。

正如原始资料的结论，直线段是最短的路。

原文：Straight segments give the shortest path.

用一句话说 — 按身高和体重记录来看，Sia 和 Moa 之间的距离是 5。这是用来和其他顾客比较的数字。

AI 判断角——可以直接相信吗？

问 AI 西娅 (160, 50) 和茉雅 (163, 54) 之间的距离，它回答"是 7"。可以直接相信吗？

检查一下

这是把横向差 3 和纵向差 4 直接相加的值（街区路线）。直线距离是 √(3² + 4²) = 5。如果答案等于两个差之和，就要怀疑是不是漏了平方和开方。

这个房间的局限 — 距离只说"有多远"。不知道两个箭头是朝同一方向还是不同方向。 → 4 号房间
用教案的 Python 代码来看（不懂也没关系）
np.linalg.norm(B - A)

B − A 箭头的长度 = 两点间距离，一行就能算出。

结果：5.0——与手算的 5 相同。

确认测验 — 西娅（160cm，50kg）与茉雅（163cm，54kg）之间的距离是？
√(3² + 4²) = √25 = 5。差直接相加是 7（街区路线），只把平方相加是 25。再开根号就是 5。
4 号房间

重叠分数与角度

两个箭头在多大程度上朝同一方向

原始资料卡片 04/10 · @eeanimation方法：重叠分数（点积）与 cos θ日常：比较两人的喜好表

为什么用这个方法

  1. 问题 — 推荐应用要找"喜好相似的人"。方向比量更重要。
  2. 前一个房间的局限 — 3 号房间的距离会把看得多的人和看得少的人视为相距很远。即使喜好相同。
  3. 解法 — 用同位置相乘后相加的重叠分数，测量两个箭头之间的角度。
简单来说 — 两个箭头朝同一方向，分数就大；垂直为 0；相反则为负数。

由害怕数学公式的助手代为提问

助手 两个箭头"朝同一个方向"，用数字要怎么表达呢？
用话来说 — 把相同位置的数字相乘再全部加起来，就是重叠分数。再除以两个长度，就得到 −1~1 之间的分数（cos θ）。
用数字算一遍
u = (3, 0), v = (2, 2) → u·v = 3×2 + 0×2 = 6
长度：‖u‖ = 3，‖v‖ = √8 ≈ 2.83 → cos θ = 6 ÷ (3 × 2.83) ≈ 0.707 → θ = 45°
喜好表（看过的动作片、爱情片部数）：西娅 (5, 1)，茉雅 (4, 2) → 22 ÷ (5.10 × 4.47) ≈ 0.965

用学校数学来看 — 向量的点积、余弦

用公式来看（展开 — 不懂也没关系）
u·v = Σ uᵢvᵢ = ‖u‖ ‖v‖ cos θ
公式片段含义
u·v重叠分数（点积） — 同位置相乘后相加的值
Σuᵢvᵢu₁v₁ + u₂v₂ + …（每个位置相乘后全部相加）
‖u‖箭头 u 的长度（3 号房间的距离）
θ（西塔）两个箭头之间的角度
cos θ把角度换成 −1 ~ 1 的分数。同方向 1，垂直 0，相反 −1
助手 cos θ 接近 1，就表示"喜好几乎相同"。

用日常来比喻

看了 5 部动作片·1 部爱情片的人，和看了 4 部·2 部的人非常相似。0.965 分。

在机器学习中

用余弦相似度寻找相似的商品·文档·客户。语言模型的注意力分数也是从重叠分数出发的。

博士公式不展开也没关系。先用数字试一试，好奇的时候再打开公式看看吧。
西娅朝同一方向分数就大，这是箭头的默契度啊！
算盘宝分数为 0 就是毫无关系，直接止损扔掉就行吧？
果蝇研究员找找变成 0 的位置。拖动 v，让它和 u 垂直。
实验面板 4重绘原始资料卡片 04 · 拖动绿色箭头 v 的末端试试

解说

把 v 移到 (0, 2)，分数为 0，并出现直角标记。

分数 0 不是"没用"，而是"互不影响"的意思。就像东西方向和南北方向。

只有当两个箭头的长度都不为 0 时，0 分才表示垂直（原始资料：nonzero vectors）。

一句话说——西娅和茉雅的喜好表得分 0.965——非常接近 1，喜好几乎朝着同一方向。

AI 判断角——可以直接相信吗？

AI 回答两位客户的余弦相似度（cos θ）是 1.3。可以相信吗？

检查一下

cos θ 永远在 −1 到 1 之间。1.3 是不可能出现的值，请让它重新计算。很可能漏掉了除以长度这一步。

这个房间的局限 — 即使知道了角度，坐标也会随"用哪把尺子量"来记数字而不同。 → 5 号房间
用教案的 Python 代码来看（不懂也没关系）
u @ v / (np.linalg.norm(u) * np.linalg.norm(v))

用重叠分数除以两个长度之积，求出 cos θ（余弦相似度）。

结果：0.7071…——与手算的 6 ÷ (3 × 2.83) ≈ 0.707 相同。

确认测验 — u = (1, 2)，v = (−2, 1) 的重叠分数是？两个箭头是什么关系？
1×(−2) + 2×1 = 0，所以是直角。按位置相乘再相加：1×(−2) + 2×1。
5 号房间

长度为 1 且互相垂直的尺子组

坐标数字随用哪把尺子来量而变化

原始资料卡片 05/10 · @eeanimation方法：用尺子组读坐标日常：更换指路基准

为什么用这个方法

  1. 问题 — 同样的数据，用什么基准（轴）来看，数字就不同。
  2. 前一个房间的局限 — 到 4 号房间为止，都理所当然地用"横·纵"尺子。用别的尺子会怎样？
  3. 解法 — 使用长度为 1 且互相垂直的尺子组（标准正交基），读坐标只需算一次重叠分数。
简单来说 — 不论用东西·南北指路，还是用"沿河·过河"指路，目的地都一样。

由害怕数学公式的助手代为提问

助手 听说换了尺子，坐标数字也会变，那还是同一个箭头吗？
用话来说 — 放上两把长度为 1、互相垂直的尺子，读出与每把尺子的重叠分数，那就是坐标。箭头的长度保持不变。
用数字算一遍
基本尺子：v = (3, 2) → v·e₁ = 3，v·e₂ = 2
旋转 45° 的尺子：e₁ = (0.71, 0.71)，e₂ = (−0.71, 0.71) → 坐标 (3.54, −0.71)
长度确认：3.54² + 0.71² ≈ 12.5 + 0.5 = 13 = 3² + 2²

用学校数学来看 — 坐标、向量的分量、单位向量

用公式来看（展开 — 不懂也没关系）
v = 3e₁ + 2e₂, eᵢ·eⱼ = 1 (同一把尺子), 0 (不同尺子)
公式片段含义
e₁, e₂尺子组中的两把尺子
v = 3e₁ + 2e₂沿 e₁ 方向 3，沿 e₂ 方向 2
eᵢ·eᵢ = 1每把尺子长度为 1
eᵢ·eⱼ = 0 (i ≠ j)不同的尺子互相垂直
坐标 = v·eᵢ与那把尺子的重叠分数就是坐标
助手 数字变了，平方和 13 却没变。因为箭头本身没变！

用日常来比喻

同一个地点，也可以分别用"向东 3、向北 2"和"沿河 3.5、过河 −0.7"来指路。

在机器学习中

独热编码给每个类别一把长度为 1 的垂直尺子。主成分分析（PCA）把尺子组转向数据分布最广的方向。

博士旋转尺子组，箭头不变。只是数字变了。
茉雅那坐标不同，不就是不同的数据了吗？
果蝇研究员用滑块旋转尺子组，盯着平方和看。
实验面板 5重绘原始资料卡片 05 · 旋转尺子组试试

解说

正如原始资料的结论，坐标取决于所选的尺子组。

原文：Coordinates depend on the chosen basis.

但长度和角度不变。所以换了尺子，仍是同样的数据。

这个房间的局限 — 用尺子组读出了坐标，但无法正好命中正确答案时，还没有挑选"最接近的答案"的方法。 → 6 号房间
确认测验 — 在长度为 1 且互相垂直的尺子组中，v 的第一个坐标怎么求？
坐标 = v·e₁。这是因为尺子长度为 1 且彼此垂直。如果尺子组长度为 1 且互相垂直，一次重叠分数就是坐标。
